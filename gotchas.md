- VLCKit 3.7.3's wrapper uses asynchronous stop; its patched backend reports stopped before resource shutdown finishes. Serialize the public synchronous C stop off the main thread, preserving media observer lifetime. The relevant upstream patch is `libvlc/patches/0024-lib-media_player-add-stop-set_media-async-support.patch` in tag `3.7.3`.
- Snapshot creation synchronously waits up to 500 ms for a new frame and may report success without saving a file. Run it on the playback session's serial background queue, then check the output. Blocking the main thread here can prevent the frame from rendering. Use the backend's `isPlaying`, not VLCKit's last cached state, to monitor a healthy feed.
